# Aethera — Security

## Security Philosophy

Security is a fundamental principle of the Aethera project.

Aethera aims to provide a transparent and responsible environment for digital asset information while minimizing unnecessary risks and complexity.

---

## Smart Contract Security

The AE2 token uses a simple ERC-20 contract architecture based on OpenZeppelin's ERC-20 implementation.

The contract is designed to avoid unnecessary complexity and does not rely on a proxy architecture in the documented source.

Users should always verify the deployed contract and its live state through trusted blockchain sources.
