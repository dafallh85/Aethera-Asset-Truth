# Contributing to Aethera

Thank you for your interest in contributing to Aethera.

Aethera aims to build a clear, transparent, and accessible technical information layer for digital assets.

## How to Contribute

Contributions may include:

- Documentation improvements
- Technical suggestions
- Website improvements
- Developer resources
- Security reports
- Feature ideas
- Bug reports
- Web3 ecosystem research

## Contribution Guidelines

Please keep contributions:

- Clear
- Accurate
- Respectful
- Relevant
- Technically responsible

Do not submit misleading information, unauthorized financial claims, or content presented as verified when it has not been verified.

## Pull Requests

Before submitting a pull request:

1. Clearly describe the proposed change.
2. Explain why the change is useful.
3. Keep changes focused and organized.
4. Verify technical information before submitting it.
5. Avoid including private keys, seed phrases, passwords, or other sensitive information.

## Issues

When reporting an issue, provide:

- A clear description
- Steps to reproduce the issue when applicable
- Expected behavior
- Actual behavior
- Relevant technical information

## Security

Do not publicly disclose sensitive security vulnerabilities.

For security-related issues, follow the guidance in `SECURITY.md`.

## Code of Conduct

All contributors are expected to communicate respectfully and constructively.

Harassment, abuse, impersonation, malicious behavior, and intentionally misleading contributions are not acceptable.

## Disclaimer

Contributions to this repository do not constitute financial, investment, trading, legal, or professional advice.

Aethera reserves the right to review, modify, reject, or remove contributions that do not align with the project's goals or standards.
