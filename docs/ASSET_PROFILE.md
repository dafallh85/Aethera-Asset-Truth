# Aethera Asset Profile

## Overview

An Aethera Asset Profile presents structured technical information about a digital asset in a clear and accessible format.

## Core Information

Each profile may include:

- Asset Name
- Symbol
- Network
- Contract Address
- Token Standard
- Total Supply
- Decimals
- Contract Verification
- Ownership
- Mint Function
- Burn Function
- Transfer Restrictions
- Buy Tax
- Sell Tax
- Proxy Status
- Liquidity
- Distribution
- Important Events

## Example: AE2

### Basic Information

**Name:** Aethera Network

**Symbol:** AE2

**Network:** Ethereum Mainnet

**Standard:** ERC-20

**Contract Address:**

`0x552038DC7852B0Fe95987153637BA36860D6C19C`

**Total Supply:**

1,000,000,000 AE2

**Decimals:**

18

## Technical Status

Each data field should have a clear status where applicable:

- Verified
- Confirmed
- Reported
- Unverified
- Not Available
- Under Review

## Transparency

The Asset Profile should clearly distinguish technical facts from project-provided information.

Aethera should not present unverified claims as confirmed facts.

## Purpose

The Asset Profile is designed to give users a technical overview of an asset before they interact with it.

**Know the asset before you trust the asset.**
