# Aethera Data Sources

## Overview

Aethera organizes technical information about digital assets using publicly available and project-provided data.

## Primary Sources

Where applicable, information may be obtained from:

- Public blockchain data
- Verified smart contracts
- Block explorers
- On-chain transactions
- Token contract interfaces
- Official project documentation
- Official project websites
- Official project announcements

## Source Priority

When multiple sources are available, Aethera should prioritize:

1. On-chain data
2. Verified contract information
3. Official technical documentation
4. Official project information
5. Other publicly available information

## Source Transparency

Important asset information should identify its source whenever practical.

Information should not be presented as independently verified when it is based only on a project statement.

## Data Changes

Blockchain and project information can change over time.

Aethera should update asset profiles when reliable new information becomes available.

## Limitations

Aethera does not guarantee that all information is complete, permanent, or error-free.

Users should independently verify critical information before interacting with any digital asset.
