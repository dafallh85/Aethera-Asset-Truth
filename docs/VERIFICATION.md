# Aethera Verification Framework

## Overview

Aethera is designed to organize technical information about digital assets using clear verification status indicators.

The purpose is to help users distinguish confirmed technical information from information that has not been independently verified.

## Verification Categories

### Verified

Information supported by reliable blockchain or technical evidence.

### Confirmed

Information confirmed through an appropriate authoritative source.

### Reported

Information provided by a project or other source but not independently verified by Aethera.

### Unverified

Information for which sufficient evidence is not currently available.

### Not Available

Information that cannot currently be obtained or determined.

### Under Review

Information currently being examined or validated.

## Verification Principles

Aethera should:

- Separate facts from claims.
- Avoid presenting assumptions as facts.
- Clearly identify the source or basis of important information.
- Preserve the distinction between verified and unverified data.
- Update information when reliable new evidence becomes available.

## Blockchain Data

Where applicable, blockchain-based information may be checked against publicly available on-chain data.

Examples include:

- Contract address
- Token supply
- Decimals
- Ownership
- Contract permissions
- Transactions
- Token balances
- Contract verification status

## Project-Provided Information

Information supplied by a project may be useful but should not automatically be treated as independently verified.

Project claims should be clearly identified when independent verification is not available.

## Updates

Asset information may change over time.

Aethera profiles should reflect the latest available verified information while maintaining transparency about the status and source of each data point.

## Disclaimer

Verification of technical information does not constitute an endorsement of an asset, project, team, investment, or financial opportunity.

Aethera provides technical transparency information only.

**Know the asset before you trust the asset.**
